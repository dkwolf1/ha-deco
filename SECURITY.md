# Security policy

Use the latest stable ha-deco release on a supported, up-to-date version of Home Assistant.

[Report suspected vulnerabilities privately](https://github.com/dkwolf1/ha-deco/security/advisories/new). Include the affected versions and expected impact. Do not post a public issue or include credentials, session tokens or unredacted router logs.

For ordinary bugs, use the [issue tracker](https://github.com/dkwolf1/ha-deco/issues/new/choose).
